## 2. 三个工具链阻断项

### B-1 · 本机没有 Verilog 仿真器（P0，阻塞所有人）

2026-09-20 检查结果：

```
where iverilog          → 找不到
C:\iverilog\bin\        → 不存在
```

`fpga/scripts/sim.bat` 文件头记录着「Verified 2026-09-19: forward case (PASS)
and reverse case (FAIL)」，但**在当前这台机器上无法复现**。

⚠️ **在重新复现出 PASS 之前，这条记录不能当作验证依据。**

**解决办法（三选一，按推荐顺序）：**

1. `winget install --id Icarus.Verilog` —— `sim.bat` 本来就是照这个装的；
2. 去 <https://bleyer.org/icarus/> 下载安装包，装到 `C:\iverilog`；
3. 装好之后**先跑一遍 `clk_div` 的 TB**，确认能打印 `PASS` 再往下做。
   **不要跳过这一步直接写新模块**——否则又是在制造"没验证过"的代码。

> 仿真器只需要 **一个人装、三个人用**（如果都在同一台机器上）；
> 各自用自己的电脑就三个人都要装。装完在群里说一声。

### B-2 · Gowin 综合授权 hostid 不匹配（P0，阻塞上板）

```
$ gw_sh.exe check.tcl
License verification failed  License hostid not match.
```

| 项 | 值 |
|---|---|
| 授权文件 | `D:\HITSZ_FALCONS\gowin_E_C853099F0B7E.lic` |
| 文件里的 HOST_ID | `C853099F0B7E` |
| 有效期 | 2027-09-17（**没过期**） |
| 授权路径配置 | `Gowin\...\IDE\bin\gwlicense.ini`（配置本身正确） |

**没过期，但是 hostid 对不上。** 大概率原因：

> **Gowin 的 hostid 是按网卡算的，而虚拟网卡会改变 hostid。**

本机装了 FlClash（代理）和 Radmin VPN，两者都会创建虚拟网卡。
如果**申请授权时**和**现在**的网卡状态不一样（比如申请时 FlClash 开着，
现在关着），hostid 就会变，授权立刻失效——而报错信息只说"不匹配"，
不会告诉你是哪块网卡变了。

**解决办法：**

1. 用 `Gowin\...\IDE\bin\license_config_gui.exe` 查看**当前** hostid；
2. 到高云官网用这个 hostid **重新申请**一个免费 E 授权；
3. ⚠️ **申请前把所有 VPN / 代理 / 虚拟网卡都关掉**，插着网线申请，
   拿到后在**同样的网卡状态**下使用。否则下周还会再遇到一次。

> 这也是为什么 09-19 还能综合、09-20 就不行的最可能解释。
