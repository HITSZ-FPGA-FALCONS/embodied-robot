## 填写提醒

- **不要**只写「测试通过」。写通过了什么、在什么条件下通过的。
- **不要**把「在我电脑上能跑」当作结论。
- 失败记录同样要留档——尤其是「换了条件就失败」这类，往往是现场演示翻车的伏笔。
- 现场答辩环境（电源、地面、光照、蓝牙/无线干扰）与实验室不同，条件允许时应在 `docs/test/` 里单独记一份「陌生环境测试」。
