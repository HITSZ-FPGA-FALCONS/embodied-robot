## 应放内容

- BOM（器件、型号、数量、来源、到货状态）

- 板卡与摄像头、电机驱动、传感器模块的规格说明
- 机械结构草图与关键尺寸
- 硬件变更记录（谁、什么时候、改了什么、为什么）

## 本赛道（高云选题三）相关

题目指南给出的硬件范围：

- **适配板卡**：小梅哥 ACG720 / ACG750 / BX72 / ACG138-RK3588-CORE
  - 免费申请清单中，选题三对应 **小梅哥 ACG720**。指南表格写 GW5AT-LV138PG484AC1、正文写 "GW5AT-60/138K"，**并非笔误**：ACG720 确实分 60K 与 138K 两个型号。本队拿到的是 **138K**（详见 `ACG720_pinout.md`）。
  - 芯片为 **C 版**（非 B 版）。依据：主 FPGA 丝印 `2518CA0N`，第 5 位 `C` 表示 C 版。**新建工程时器件版本须选 C**（`set_device ... -device_version C`，或 IDE 工程设置里的 Device Version）。选错会导致 bitstream / Programmer 异常且报错指不到版本问题。
- **摄像头**：OV5640 / OV5647，也可用双目或更高规格兼容摄像头
- **电机驱动、姿态检测、运动执行**：由参赛队自主选型

> 板卡为**完赛后寄回**（地址见选题指南第 19 页）。若使用自备板卡，需以高云 FPGA 为核心。
