## 板卡信息

| 项 | 值 |
|---|---|
| 板型 | **ACG720-GW5AT138** |
| 器件料号 | `GW5AT-LV138PG484AC1/I0` |
| **芯片版本** | **C 版**（非 B 版）—— 依据主 FPGA 丝印 `2518CA0N`，第 5 位 `C` |
| Gowin 器件标识 | `-name GW5AT-138C`，配合 `-device_version C` |
| 封装 | PBGA484A |
| 资源 | 138240 LUT / 6120 Kb BSRAM / 298 DSP / 12 PLL |

> ⚠️ **建工程时必须选对版本。**
> 同一料号存在 `GW5AT-138B` 与 `GW5AT-138C` 两个晶圆版本，器件库里是**两条独立记录**。
> 选错会导致 bitstream / Programmer 行为异常，且报错通常指不到版本头上，很难查。
>
> 指定方式（Gowin 命令行）：
> `set_device -name GW5AT-138C GW5AT-LV138PG484AC1/I0 -device_version C`
> （`-device_version` 取值 `NA|B|C|D`；IDE 中对应工程设置的 Device Version 项。）
>
> **首次上板时的复核动作**：用 Programmer 扫描 JTAG，确认读回的器件与所选版本一致，结果记入 `docs/test/`。
> 依据说明：丝印判读来自队外资料（同款 GW5AT-138 使用者的记录），**本队尚未独立验证**——上板扫描是成本最低的确认方式。

## 基本管脚

| 信号 | 引脚 | 说明 |
|---|---|---|
| `clk` | **Y18** | 系统时钟 |
| `reset_n` | F15 | 复位（低有效） |
| `SW` / `SW0` | G22 | 按键 |
| `SW1` | D22 | 按键（仅 SPI 例程表中有） |

## SPI —— 注意有两套

**A 组（SPI 例程用，接板上 ADC）**

| 信号 | 引脚 |
|---|---|
| `SPI_M_SCLK` | N5 |
| `SPI_M_MOSI` | M5 |
| `SPI_M_MISO` | P6 |
| `SPI_M_CS` | M6 |

**B 组（FX2 例程用）**

| 信号 | 引脚 |
|---|---|
| `SPI_SCLK` | L15 |
| `SPI_MOSI` | K16 |
| `SPI_MISO` | L16 |
| `SPI_CS` | L14 |

> 板上是**两条独立 SPI 通路**，接线与约束时不要混用。

## ⚠️ 已知缺口

- **LED 引脚未收录**——注意这是**本表的覆盖缺口，不是板卡没有 LED**。
  ACG720 板载 **8 个用户 LED**（小梅哥官方 ACG720 课程含 LED 流水灯、3-8 译码器板级验证、拨码开关控制 8 路 LED）。
  本表只覆盖上面三份 USB/ADC 例程用到的信号，那三份恰好没用到 LED。
  **提取方式**：从官方教学工程的 `.cst` 约束文件里取，不要自己猜管脚。
  可搜关键词：`led`、`led[0]`、`流水灯`、`decoder_3_8`、`.cst`。
- **信号名的下划线后缀**由 PDF 文本抽取得到，个别（如 `fx2_pkt_end`）可能存在 `_n` 之类的低有效后缀未完整还原。**写约束前请对照原 PDF 页面核对拼写。**
- 本表**不含**电源、地、时钟输入、JTAG 等引脚，需查硬件图纸。
