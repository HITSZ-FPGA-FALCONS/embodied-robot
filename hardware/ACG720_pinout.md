## 板卡信息

| 项 | 值 |
|---|---|
| 板型 | **ACG720-GW5AT138** |
| 器件料号 | `GW5AT-LV138PG484AC1/I0` |
| **芯片版本** | **C 版**（依据主 FPGA 丝印 `2518CA0N` 第 5 位） |
| Gowin 器件标识 | `-name GW5AT-138C`，配合 `-device_version C` |
| 封装 | PBGA484A |
| 资源 | 138240 LUT / 6120 Kb BSRAM / 298 DSP / 12 PLL |

> ⚠️ 建工程时必须选对版本。同料号存在 `GW5AT-138B` / `GW5AT-138C` 两条独立记录，
> 选错会导致 bitstream / Programmer 异常且指不到版本头上。
> 首次上板时用 Programmer 扫描 JTAG 复核。

## 系统时钟 —— 50MHz

| 信号 | FPGA 管脚 | 方向 | 电平 |
|---|---|---|---|
| **FPGA_GCLK1** | **Y18** | I | LVCMOS33 |

> **时钟频率是 50 MHz。** 分频、波特率、PWM 频率的计算全部以此为准。
> 例：UART 115200 波特率 → 分频系数 = 50_000_000 / 115200 ≈ 434。

## ⭐ 摄像头接口 —— DVP 并口 8 位

| 信号 | 管脚 | | 信号 | 管脚 |
|---|---|---|---|---|
| COMS_D0 | J2 | | COMS_D4 | F1 |
| COMS_D1 | J1 | | COMS_D5 | G2 |
| COMS_D2 | G1 | | COMS_D6 | D1 |
| COMS_D3 | H2 | | COMS_D7 | E1 |
| **COMS_PCLK** | B1 | | **COMS_XCLK** | M17 |
| **COMS_HREF** | A1 | | **COMS_VS** | B2 |
| **COMS_SDAT** | L18 | | **COMS_SCLK** | M20 |
| COMS_RST | N20 | | | |

全部 `LVCMOS33`。

> ### 这一条决定了摄像头怎么买
>
> 板载接口是 **DVP 并口（8 位数据 + PCLK/HREF/VS）**，配置口是 **SCCB（I²C 从机，SDAT/SCLK）**。
> **不是 MIPI。**
>
> - ✅ 要买 **DVP 并口输出的 OV5640 / OV5647 模块**
> - ❌ **ALINX AN5641（MIPI 5MP，¥219）插不上** — 接口类型不符
> - ⚠️ 买之前确认模块**引脚定义与 FPC 排线**匹配本板接口，不能只看"OV5640"三个字
>
> 原表该分组共 15 行，上表已完整收录。
