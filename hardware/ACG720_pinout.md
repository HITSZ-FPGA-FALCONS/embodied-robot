## 板卡信息

| 项 | 值 |
|---|---|
| 板型 | **ACG720-GW5AT138** |
| 器件料号 | `GW5AT-LV138PG484AC1/I0` |
| Gowin 综合时器件名 | `-name GW5AT-138B`（或 `GW5AT-138C`，**待确认**） |
| 封装 | PBGA484A |
| 资源 | 138240 LUT / 6120 Kb BSRAM / 298 DSP / 12 PLL |

> ⚠️ 同一料号存在 **138B / 138C 两个晶圆版本**，见 `docs/UPSTREAM.md` 与 Gowin 器件库。
> 选错会导致约束/时序与实际芯片不符。确认方式：看芯片丝印，或问厂家。

## 基本管脚

| 信号 | 引脚 | 说明 |
|---|---|---|
| `clk` | **Y18** | 系统时钟 |
| `reset_n` | F15 | 复位（低有效） |
| `SW` / `SW0` | G22 | 按键 |
| `SW1` | D22 | 按键（仅 SPI 例程表中有） |

## 串口

| 信号 | 引脚 |
|---|---|
| `uart_tx` | M15 |
| `uart_rx` | J21 |

## SPI —— 注意有两套

**A 组（SPI 例程用，接板上 ADC）**

| 信号 | 引脚 |
|---|---|
| `SPI_M_SCLK` | N5 |
| `SPI_M_MOSI` | M5 |
| `SPI_M_MISO` | P6 |
| `SPI_M_CS` | M6 |

**B 组（FX2 例程用）**

| 信号 | 引脚 |
|---|---|
| `SPI_SCLK` | L15 |
| `SPI_MOSI` | K16 |
| `SPI_MISO` | L16 |
| `SPI_CS` | L14 |

> 板上是**两条独立 SPI 通路**，接线与约束时不要混用。

## ⚠️ 已知缺口

- **没有 LED 引脚**。三份例程都只用数码管，未出现 LED。做「点灯」最小例程前，LED 引脚需另查硬件图纸或原理图。
- **信号名的下划线后缀**由 PDF 文本抽取得到，个别（如 `fx2_pkt_end`）可能存在 `_n` 之类的低有效后缀未完整还原。**写约束前请对照原 PDF 页面核对拼写。**
- 本表**不含**电源、地、时钟输入、JTAG 等引脚，需查硬件图纸。
