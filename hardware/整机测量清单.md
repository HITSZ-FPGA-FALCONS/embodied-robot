# 整机测量清单

> 2026-09-19 · 量完这一份，底盘选型和结构设计就能一次定下来
> 单位统一用 **mm**，重量用 **g**
> 钢尺量到 1mm 够用；有游标卡尺更好（尤其是孔径和板厚）

---

## A. ACG720 开发板（最紧急）

### A1. 外形

| # | 测什么 | 值 | 怎么量 |
|---|---|---|---|
| 1 | PCB 长 | ____ mm | 板子边缘到边缘 |
| 2 | PCB 宽 | ____ mm | 同上 |
| 3 | 板厚 | ____ mm | |
| 4 | **最高元件到板面高度** | ____ mm | 排针座、HDMI、网口、SD 卡座里最高的那个 |
| 5 | 重量 | ____ g | 厨房秤就行 |

> **第 4 项容易漏。** 它决定上下两层之间要留多少间隙——
> 如果按 PCB 厚度算，装上去会发现排针顶到上层板。

### A2. 安装孔

| # | 测什么 | 值 |
|---|---|---|
| 6 | 孔径 | ____ mm（φ） |
| 7 | 孔距（横向） | ____ mm |
| 8 | 孔距（纵向） | ____ mm |
| 9 | 孔到最近板边的距离 | ____ mm |
| 10 | 孔的数量 | ____ 个 |

> **孔距量「孔中心到孔中心」**，不是边缘到边缘。
> 这组数决定底盘底板要钻什么孔——**四轮套件的底板孔位是固定的，装不上就得自己转接板**。

### A3. 接口突出方向与位置

| 接口 | 在板的哪条边 | 突出 PCB 边缘多少 mm | 突出板面多高 mm |
|---|---|---|---|
| HDMI | | | |
| 网口 | | | |
| USB | | | |
| SD 卡座 | | | |
| 电源插座 | | | |
| TFT / 排针 | | | |
| 摄像头 FPC 座 | | | |

> **这组决定板子怎么摆放。** 线缆要从某一边出，那一边就不能贴墙、不能顶着别的模块。
> 比如网口如果朝右，右边就得留出网线的弯折空间。

### A4. 扩展口位置

| # | 测什么 | 值 |
|---|---|---|
| 11 | `GPIO0`（36 位扩展口）在板的哪一侧 | |
| 12 | 该排针的引脚间距 | ____ mm（通常 2.54） |
| 13 | 从排针到板边的距离 | ____ mm |

> 这是接电机驱动 / 编码器 / IMU 的地方，**决定线怎么走**。

## C. 整机层面的推算

量完 A、B 后填这几项：

| # | 算什么 | 值 | 算法 |
|---|---|---|---|
| 14 | **最大单件尺寸** | ____ × ____ mm | 取 A1 和 B 里最大的那个 |
| 15 | **需要的底板最小面积** | ____ × ____ mm | 第 14 项 + 每边 20mm 走线余量 |
| 16 | **需要的层数** | ____ 层 | 板卡 / 电池 / 传感器通常要分层 |
| 17 | **整机预估重量** | ____ g | A1+B 全部相加 + 支架线材 ~200g |
| 18 | **重心大致位置** | | 重的件（电池）放低、靠中 |

> **第 15 项直接筛底盘**：底板的可用面积必须 ≥ 这个数。
> **第 17 项决定电机扭矩需求**——这是电机选型链的链头。

## D. 量完之后能定什么

| 数据 | 决定 |
|---|---|
| 15（底板最小面积） | **13 个底盘候选缩到 2~3 个** |
| 17（整机重量） | 电机扭矩需求 → 减速比选型 |
| A2（安装孔） | 需不需要做转接板 |
| A3（接口方向） | 板卡在底板上的摆放位置与朝向 |
| A4（扩展口位置） | 电机/编码器走线路径 |
