# 底盘方案三选一

## 一句话区分

> **阿克曼像汽车：高速、自然、效率高，但转弯必须「走弧线」。**
> **差速像扫地机器人 / 坦克：低速灵活、控制直接，可以原地转，但转弯时更容易滑。**

**阿克曼更像「车辆」，差速更像「移动机器人」。而本题做的是具身智能移动机器人。**

## 硬约束：题目要求「定点旋转」

选题指南任务2 把基本运动能力拆成四项：

```
前进  /  后退  /  转向  /  定点旋转
```

**「转向」和「定点旋转」被分开列出，说明它们不是一回事。**

阿克曼底盘靠前轮转角产生曲率，转弯半径 `R ≈ L / tan(δ)`。前轮最大转角 δ 有限，所以 `Rmin > 0`——**只能沿圆弧转向，不能保持位置原地改变航向。**

这不是 Verilog 写得好不好、PID 调得好不好的问题。**机械自由度没有，就是没有。**

### 四项动作对照

| 动作 | 阿克曼 | 差速 |
|---|---|---|
| 前进 | ✅ | ✅ |
| 后退 | ✅ | ✅ |
| 转向 | ✅ | ✅ |
| **定点旋转** | ❌ | ✅ |

差速实现原地旋转：

```
左轮 +v，右轮 −v
v_robot ≈ (vL + vR)/2 = 0
ω     ≈ (vR − vL)/轮距 ≠ 0
```

### 为什么这条不是"加分项"

如果评测按字面检查「保持位置原地旋转 90°/180°/360°」，阿克曼从运动学上就不具备这个动作。

**它还会连带影响导航**：前向摄像头看不到后方目标时，差速车可以「原地旋转 → 摄像头扫过 360° → 找到目标 → 对准」，阿克曼只能「前进 → 打方向 → 走弧线 → 倒车 → 再调姿」。

## 完整对照

| 对比维度 | 阿克曼转向 | 差速驱动 |
|---|---|---|
| 转向方式 | 前轮改变转角，车体沿圆弧运动 | 左右轮速度不同产生转向 |
| **原地旋转** | ❌ 标准结构做不到 | ✅ 左右轮反转即可 |
| 最小转弯半径 | 有，受轴距与最大舵角限制 | 理论可为 0 |
| 机械结构 | 转向舵机 + 转向连杆，较复杂 | 两侧独立驱动，结构简单 |
| 控制模型 | 运动学更复杂，要考虑转角 | 很直观，左右轮速度即可 |
| 编码器里程计 | 通常还需转向角信息 | 左右轮编码器直接计算 |
| 低速机动性 | 一般 | **非常强** |
| 狭窄空间 | 不占优势 | **非常适合** |
| 高速稳定性 | **好**（机械结构约束车体朝向） | 相对一般（左右轮误差易偏航） |
| 运动自然程度 | 类似汽车，非常自然 | 转向更「机器人化」 |
| 轮胎磨损 | 正常转向时小 | **原地转 / 急转产生侧滑与磨胎** |
| 能量效率 | 通常更好 | 原地旋转与滑移时损耗较大 |
| 精确运动学 | 理想情况下较稳定 | **受轮胎打滑影响明显** |
| FPGA 控制实现 | 舵机角度 + 驱动电机 | **左右轮双闭环，很适合 FPGA** |

> **阿克曼的优势是真实的**：正常转弯时四轮各自沿圆弧滚动，几乎不需要横向摩擦，因此
> 高速稳定、磨损小、效率高。若赛题是「宽道快速跑圈 / 循迹 / 过弯」，阿克曼通常更合理。
> **本题不是那种题。**

### 滑移：**只发生在四轮全驱**，不在两轮差速

这条容易搞混，**包括本文件早先的版本也搞混过**：

| 结构 | 原地旋转时 | 打滑？ |
|---|---|---|
| **2 驱动轮 + 万向轮** | 每个驱动轮沿自己圆周的**切向**滚动 | ❌ **纯滚动，不打滑** |
| **4 轮全驱**（skid-steer） | 前后轮不都在切向上，被迫横向刮擦 | ✅ **打滑明显** |

两轮差速原地旋转时，左轮在半径 `d/2` 的圆上、右轮反向等速——
**轮子的滚动方向正好是圆周的切线方向**，是纯滚动，万向轮自己转向即可。

**所以「原地旋转会打滑」这个说法只对 skid-steer 成立，不能推广到所有差速底盘。**

#### 对里程计的实际影响

| 场景 | 精度来源 | 误差性质 |
|---|---|---|
| **定点旋转**（2 轮差速） | 编码器 → 角度 | **标定误差**（轮径、轮距），非滑移 |
| **长距离导航** | 编码器 → 航向累积 | **漂移**（左右轮径差、加速打滑缓慢累积） |

> 定点旋转的典型误差：轮径标偏 5% → 转 90° 实际 85.5°。
> 这是**一次性标定问题**，不是不确定性，可以修。

#### 陀螺仪在这里的真实定位

**队友的判断是准确的**：

> **只用转 → 不需要陀螺仪；要导航、定位 → 才需要。**

| 用途 | 需要陀螺仪吗 |
|---|---|
| 定点旋转 | ⚪ **不需要**——2 轮差速是纯滚动，编码器够（前提：轮径/轮距标定准确） |
| 长距离航向校正 | ✅ **有价值**——编码器航向会缓慢漂移，陀螺仪融合可校正 |

#### 但 IMU 仍然是**必须件**——理由不是导航

选题指南**任务1** 明确列出：

> 任务1：实时显示
> • 摄像头采集与图像显示
> • **IMU 姿态数据采集**
> 实时显示：• 摄像头画面 • **姿态角信息**

**「IMU 姿态数据采集 + 姿态角实时显示」是题目明列的任务项。**

```
买 IMU 的理由 = 任务1 要求，不是导航需要
```

既然要买，**ICM42688（约 ¥32）比 MPU6050 只贵二十来块**——直接上好的，
省得以后真要做陀螺仪融合时被零漂拖累。

#### 若走方案 B，目标形态应是「后两轮驱动 + 前轮万向轮」

而不是四轮全驱。这正好回到 B 的第一条前提：**前轮必须能变成自由脚轮。**
四轮全驱不仅改动更大，还会引入上面那张表里的滑移问题。

## 三个候选方案

### A. 保留阿克曼（不改造）

```
阿克曼底盘 + M10 激光雷达 + 前摄像头
```

| | |
|---|---|
| ✅ 优点 | 旧车利用率最高，什么都不用动 |
| ❌ 缺点 | **丢掉定点旋转**（任务2 少一项）<br>视觉仍有盲区，周向搜索做不到<br>导航运动学更复杂 |
| 判定 | **不推荐**——用省下的工作量换一个明确的动作项，不划算 |

### B. 大改旧阿克曼成差速

```
拆舵机，前轮改自由脚轮，后轮左右独立驱动
```

| | |
|---|---|
| ✅ 优点 | 复用现有电机 / 电源模块 / 驱动板 |
| ⚠️ **前提** | 见下方「B 的三个前提」 |
| ❌ 风险 | 机械改装成本**未知，可能高于直接买** |

**⚠️ 早先的一个错误判断（已推翻）**

曾经认为「拆掉前轮舵机即可变差速」——**不成立**。

前轮即使拆掉舵机，仍受转向拉杆的**滚动约束**，不是自由万向轮。此时左右后轮反转，前轮会**拖胎侧滑**：机械受力大、电流大、里程计不准。

**真正的差速结构需要**：两驱动轮 + 自由万向轮（或四轮滑移差速）。

**B 的三个前提：**

1. 前轮能改成**自由脚轮**，或底盘能重新构型
2. 底板有**万向轮安装孔位**
3. 后轴双电机是**左右独立驱动**（不是共用差速器）

三条缺一条，B 的成本就接近甚至超过 C。

### C. 直接买成熟差速底盘

```
差速底盘 + 左右编码器 + M10 + 前摄像头
```

| | |
|---|---|
| ✅ 优点 | 题目四项动作与运动学**几乎一一对应**；无改装风险；机械部分立刻可用 |
| ❌ 缺点 | 放弃旧车的电机 / 电源 / 驱动复用；需另购电机与驱动 |
| 成本 | 底盘 ¥30~60 + 带编码器电机 ¥65×2 + 驱动 ¥10×2 ≈ **¥200** |
| 判定 | **就赛题结构看最贴题** |

> ⚠️ 有一样东西**不能**替 C 做决定：那块队友自绘的驱动板。它现在虽无维护，
> 但如果它工作正常且接口清楚，复用它能省下的不只是钱，还有**调试别人的板子的时间**。

## 感知方案（与底盘选型独立）

```
M10 激光雷达 360°  →  周围有没有障碍物、多远        （避障 / 测距）
固定前摄像头       →  那是不是我要找的目标（红色水瓶）（识别）
差速底盘定点旋转   →  补上「视觉 360° 搜索」        （目标搜索）
```

> ⚠️ **360° 雷达 ≠ 360° 视觉识别。**
> 雷达知道「后面有个东西」，但不知道「那是不是红色水瓶」。
> **周向目标搜索仍然依赖车体旋转 + 摄像头**——这是差速底盘不可替代的价值。

M10 实测规格：360° / 10–20 Hz / 10,000 点·s⁻¹ / ±3 cm / 905 nm Class 1 /
探测距离 10 m @10% 反射率 · 25 m @70% 反射率 / **串口 460800 bps** / 约 200 g

## 拍板前需要确认的信息

| # | 要确认的 | 影响哪个方案 |
|---|---|---|
| ① | 前轮拆舵机后能否变自由脚轮？底板有万向轮孔位吗？ | **决定 B 是否可行** |
| ② | 后轴双电机是左右独立，还是共用差速器？ | **决定 B 是否可行** |
| ③ | 编码器线数、输出电平（3.3V / 5V） | B / C 都要 |
| ④ | 电机型号、额定电流、堵转电流、减速比 | B / C 都要（供电树） |
| ⑤ | 驱动板是否还能用？原理图与固件在谁手上？ | **决定 B 能省多少** |

**① ② ⑤ 一看，B 还是 C 当场就能拍。**
