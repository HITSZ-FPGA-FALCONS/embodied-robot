## 为什么先冻结再买

> **最大的采购风险不是「买贵了」，而是「过早买错」。**

电机、驱动、编码器、电池、DC-DC 是一**条链**，不是五个独立采购项：

```
整机重量 + 目标速度 + 轮径
        ↓
     电机扭矩 / 转速需求
        ↓
   电机额定电流 / 堵转电流
        ↓
驱动器额定 / 峰值电流  ──→  散热、保护
        ↓
电池容量、放电倍率、DC-DC 规格、线径、保险丝
```

**链头没定，链尾不能买。** 典型的失败形态是：

```
电机不错 + 驱动不错 + 编码器不错 + 电池不错
            → 装在一起不好用
```

「参数都对但装不上」和「参数都对但推力不够」是两种最常见的返工。

### 底盘：结论已修正，**尚未冻结**（2026-09-19）

**已确定的**：

- **场地**：往年均在南京高校教室（室内平整地面）→ 不需要悬挂 / 履带
- **硬约束**：题目任务2 明确列出「**定点旋转**」。标准阿克曼存在非零最小转弯半径（`R = L/tan(δ)`），
  **结构上做不到零半径原地转**，这不是调参能补的。→ **差速拓扑天然更贴题**
- **现有资源**：队友有一台阿克曼车，**2 个电机 + 2 个编码器**，电机驱动板与电源模块可考虑复用

**⚠️ 已推翻的错误结论**：早先判断「拆掉前轮舵机即可变差速」——**不成立**。

前轮即使拆掉舵机，仍受转向拉杆的**滚动约束**，不是自由万向轮。
此时左右后轮反转，前轮会**拖胎侧滑**，机械受力大且里程计不准，不等于得到一个干净的差速底盘。
**真正的差速结构需要：两驱动轮 + 自由万向轮（或四轮滑移差速）。**

## 第二步：推导（填完才算冻结）

### 2.1 转速需求

```
轮转速 n = v / (π·D) × 60        [rpm]
电机转速 = n × 减速比
```

### 2.2 扭矩需求

```
每轮牵引力 F = (m·a + m·g·μ) / N轮     ← a 取起步加速度，μ 取滚动阻力系数
每轮扭矩   T = F × D/2                   [N·m]
电机扭矩   = T / (减速比 × 传动效率)
```

> **选型时扭矩要留 2 倍以上余量**（用于加速、爬微坡、地面不平时克服阻力）。

### 2.3 电流推导

```
电机工作电流 ≈ 堵转电流 × (实际负载扭矩 / 堵转扭矩)
总电流       = 电机数 × 单机电流 + 逻辑部分电流
峰值电流     = 电机数 × 堵转电流          ← 用这个选驱动器和电池
```

| 项 | 值 | 备注 |
|---|---|---|
| 单电机额定电流 | ___ A | 查电机规格书 |
| 单电机堵转电流 | ___ A | **查规格书，不要用额定×2 猜** |
| 电机数量 | ___ | |
| 逻辑部分电流 | ___ A | FPGA 板 + 摄像头 + 传感器，估 1~2 A |
| **总峰值电流** | ___ A | ← 后面全部按这个算 |

### 2.4 供电树

```
电池 ___V ___mAh (___C)
  ├─→ 电机驱动（直供或降压）
  ├─→ DC-DC → 5V  ___A   → 传感器 / 舵机
  └─→ DC-DC → 3.3V ___A  → FPGA 逻辑侧（注意与电机电源分离）
共地
```

| 轨 | 电压 | 供给对象 | 峰值电流 | 选型余量 |
|---|---|---|---|---|
| 电机 | | 驱动器 | | ≥1.5× |
