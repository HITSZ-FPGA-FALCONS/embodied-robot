## 升级思路

> **把钱花在「减少调试痛苦」和「防止归零」上，不是花在「更高的性能参数」上。**

按这个原则，升级版做三件事：

1. **加一台逻辑分析仪**（ROI 最高，见下）
2. **IMU 升一档**（ICM42688，实查只要 ¥32）
3. **关键件备件加倍**

**明确不做**：4WD、大功率电机、激光雷达、高线数光电编码器——都会增加复杂度和电源干扰，对现在的阶段是负担不是收益。（理由见文末「为什么不升级这些」）

## 逻辑分析仪：为什么它是本次升级 ROI 最高的一项

本仓库 `fpga/README.md` 的硬性要求：

> 「写完在 PR 里附**波形截图**。**没有波形的 FPGA PR 视为未验证。**」

- **仿真波形**验证模块**内部**逻辑
- **逻辑分析仪**验证**板级真实电信号**：编码器 A/B 相、PWM 输出、SPI 时序、UART 帧
- 两者互补，不重复

价格（本次实查）：

| 规格 | 价格 | 说明 |
|---|---|---|
| 8 通道 24MHz 兼容款 | **¥30~50** | 便宜，但抓编码器+PWM+SPI 会不够用 |
| **16 通道 100MHz（推荐）** | **~¥300** | 编码器 4ch + PWM 2ch + SPI 4ch 可同时抓 |
| 16 通道 200MHz | ~¥860 | 超出需求 |
| 原厂 Saleae Logic Pro 16 | ¥12,399 | ❌ 完全没必要 |

> **16 通道不是奢侈**：两个电机的 A/B 相就占 4 个通道，再加 PWM 2 个、SPI 4 个——8 通道立刻见底。
>
> 高云工具链自带在线逻辑分析仪（GAO），但它占 FPGA 内部资源、只能看内部信号。**外部逻辑分析仪看的是板子上真实的电压波形**，调编码器和电源问题时不可替代。

## ⚠️ 为什么不升级这些

| 不升级 | 原因 |
|---|---|
| **4WD 四驱** | 电机与编码器翻倍 → 更多 PWM 通道、更多计数逻辑、更多调试变量。**对刚起步的团队，减少变量比增加性能重要。** 你们计划里写的也是「双轮差速」 |
| **大功率电机** | 大电流 → 电源干扰更严重 → 更多「莫名其妙复位」。`hardware/README.md` 里已经警告过这一点 |
| **500 线光电编码器** | 精度高，但脉冲频率高，FPGA 端计数逻辑要跟得上；且对安装和灰尘敏感。霍尔 13 线（四倍频后 ~52 脉冲/转）对走路径点够用 |
| **激光雷达**（¥500~900） | 题3 不要求建图，前向避障用「超声 + ToF」足够。这笔钱给备机更值 |
| **更好的摄像头** | 题3 的 AI 扩展只占 **5%**，且 FPGA 端也处理不过来高帧率 |

> **现在限制你们成绩的不是硬件，是仓库里 RTL 的代码量。** 再好的电机，没有 PWM 模块它也不转。

## ⚠️ 三个必须确认的技术约束

### 1. 电平：FPGA 的 IO 是 3.3V

**5V 信号直接进 FPGA 的脚会打坏芯片。**
- JGB37-520 霍尔编码器输出电平需确认；若为 5V，配电平转换模块
- ICM42688 / 测距模块同理
- 各模块供电电压不同（3.3V / 5V），下单时一并买电平转换与稳压

### 2. 电源：电机与逻辑必须分离

本仓库 `hardware/README.md` 已记录：

> 电机启停的电流冲击是最常见的「莫名其妙复位」原因

- 电机驱动单独供电，逻辑（FPGA + 传感器）单独供电，**共地**
- 降压模块按**电机堵转电流**算余量，不是额定电流
- 一并买电源指示与保险丝

### 3. 摄像头：等硬件图纸

选题指南规定 **OV5640 / OV5647**，但**没说板子怎么接**。接口规格（DVP 并口 / MIPI / FPC 针数）只有 ACG720 硬件图纸能回答。

**解锁方式**：从网盘**单独下载「硬件图纸」子包**（不必等 23G 全量）。

价格参考：通用模块 ¥30~80；正点原子 ~¥150；ALINX 单目 ¥219、双目 ¥439。**贵的不一定对，要匹配板载接口。**
