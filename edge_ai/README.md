# edge_ai/ — 边缘 AI 协同

仅保留与**最终机器人集成**相关的推理、接口与部署内容；训练工程可独立建仓库。

## 本赛道（高云选题三）的相关约束

AI 扩展在评分中只占 **5%**，而 FPGA 实时感知与控制占 40%、系统稳定性占 25%。所以本目录的优先级是：

1. **先保证不拖累主链路** —— AI 侧异常时，FPGA 的底层控制必须仍然有效。这不是加分项，是「系统稳定性 25%」的组成部分。
2. **接口边界要清楚** —— FPGA 与边缘平台之间交换什么、以什么频率、丢了怎么办，先写进 `docs/architecture/`。
3. 最后才是识别精度、模型选型这类指标。

## 应放内容

- 与 FPGA 的通信接口实现（协议、帧格式、超时与重传）
- 模型部署与推理调用代码
- 从识别结果到高层指令的转换逻辑
- 部署说明与版本记录

## 不放内容

- 训练工程与数据集（独立仓库）
- 模型权重（见 `.gitignore`）
- 与最终集成无关的一次性实验
